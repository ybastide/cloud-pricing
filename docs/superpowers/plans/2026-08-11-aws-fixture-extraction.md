# AWS Fixture Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shrink AWS's contribution to the production JS bundle by extracting only the
fields the app uses into a small, committed `fixtures/aws/instances.json`, generated by a
build-time script — mirroring the extraction pattern GCP already uses via
`scripts/extract-gcp.mjs` — instead of shipping AWS's full 682 KB raw SKU catalog to the
browser.

**Architecture:** A new `scripts/extract-aws.mjs` reads the raw, already-committed
`fixtures/aws/index.json` and writes a flat `fixtures/aws/instances.json` containing only
the 7 fields `normalizeAws` reads (under their original AWS field names, so `normalizeAws`
needs zero changes) plus `region`/`operatingSystem` hoisted to the top. `awsInstances.js` is
rewired to import the new fixture instead of the raw one, becoming structurally identical to
`gcpInstances.js`. The now-unused `normalizeAllAws` helper is deleted; the substantial
real-fixture regression test that currently exercises it is retargeted to the new fixture,
not deleted.

**Tech Stack:** Node.js ESM scripts (matching `scripts/extract-gcp.mjs`), Vitest.

## Global Constraints

- `fixtures/aws/index.json` (raw source) stays committed unchanged. The new
  `fixtures/aws/instances.json` is a generated, also-committed build artifact — same
  arrangement as GCP's raw HTML fixtures + generated `fixtures/gcp/instances.json`.
- The extracted `instances` array entries use AWS's original raw field names as keys
  (`'Instance Type'`, `'Instance Family'`, `vCPU`, `Memory`, `Storage`,
  `'Network Performance'`, `price`) — not renamed/shortened — so `normalizeAws` in
  `src/lib/data/normalize.js` requires zero changes.
- `normalizeAws` itself is unchanged. No change to `App.svelte`, `query.js`, `urlState.js`,
  `InstanceTable.svelte`, `Toolbar.svelte`, or any GCP-side file.
- No dynamic `import()` / code-splitting / async loading state — this plan is a pure
  build-time fixture change.
- The `normalizeAllAws` function is deleted (no production callers once `awsInstances.js` no
  longer needs it), but the real-fixture regression test currently built on top of it
  (`normalize.test.js`, `describe('normalizeAll over the real fixture', ...)`, lines
  202–262) is retargeted to the new fixture, not deleted — it asserts real properties of the
  full 1322-row dataset (finite numerics, 390 arm-classified rows, positive price/vCPU,
  unique types, etc.) and is renamed to `'normalizeAws over the real fixture'` to match the
  naming of the equivalent `'normalizeGcp over the real fixture'` block already in the same
  file.
- Before deleting `normalizeAllAws`, a one-time implementation-time check (not a committed
  test) proves the old and new code paths produce byte-identical output against the real
  fixture.

- [ ] **Step 3: Write the extraction script**

Create `scripts/extract-aws.mjs`:

```js
import { readFileSync, writeFileSync } from 'node:fs'

export function extractAwsInstances(rawIndex) {
  const [region] = Object.keys(rawIndex.regions)
  const rows = Object.values(rawIndex.regions[region])
  const operatingSystem = rows[0]['Operating System']

  const instances = rows.map((row) => ({
    'Instance Type': row['Instance Type'],
    'Instance Family': row['Instance Family'],
    vCPU: row['vCPU'],
    Memory: row['Memory'],
    Storage: row['Storage'],
    'Network Performance': row['Network Performance'],
    price: row['price'],
  }))

  return { region, operatingSystem, instances }
}

function main() {
  const rawIndex = JSON.parse(readFileSync('fixtures/aws/index.json', 'utf8'))
  const result = extractAwsInstances(rawIndex)

  writeFileSync('fixtures/aws/instances.json', JSON.stringify(result, null, 2) + '\n')

  console.log(`region: ${result.region}`)
  console.log(`operatingSystem: ${result.operatingSystem}`)
  console.log(`instances: ${result.instances.length} rows`)
}

if (import.meta.url === `file://${process.argv[1]}`) {
  main()
}
```
